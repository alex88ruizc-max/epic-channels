Mis cuentas

¿Cómo pido el código?

1. Netflix: pide el código o el enlace ("Estoy de viaje", "Actualizar Hogar").

2. Espera 30 a 60 segundos y toca Ver código. Los enlaces duran 15 minutos.

3. Si una cuenta vence, renueva para seguir usándola.

Cuenta de Netflix

No se guarda la clave de la cuenta. Si dejas el cliente vacío, queda "sin asignar".

Puedes pegar solo el correo, solo el nombre, o una línea completa: correo ; cliente ; plan ; precio ; inicio ; whatsapp

Se crea una casilla por perfil. Luego tocas Asignar en cada una para ponerle cliente, plan, precio y fecha de pago.

Inicio del periodo = día del último pago. El próximo pago se calcula con los meses del plan; solo cámbialo a mano si la fecha real es otra.

Carga en bloque

Una cuenta por línea, separando con punto y coma (;):

correo ; cliente ; plan ; precio ; fecha de inicio ; whatsapp ; perfil ; pin ; plataforma
  • Plan: 1, 2 o 3 (meses). Fecha de inicio = día del último pago (21/10/2026 o 2026-10-21). El vencimiento se calcula solo con el plan.
  • WhatsApp es opcional. No pegues claves: no se guardan.
  • Perfil y PIN solo para cuentas compartidas: una línea por perfil, con el mismo correo.
  • Plataforma (opcional): Netflix, Disney+, Max, Prime Video, Spotify... Si la dejas vacía, es Netflix.
  • Solo el correo = cuenta sin asignar. Con cliente = asignada (pendiente de migrar hasta que lo vincules).
